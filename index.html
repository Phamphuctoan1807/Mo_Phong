🚀 Hướng dẫn đưa lên GitHub Pages trong 3 phút

Dự án này là ứng dụng web tĩnh thuần túy (HTML/CSS/JS không phụ thuộc framework hay build tool), sẵn sàng để chạy miễn phí trên GitHub Pages bất cứ lúc nào!

  1. Tạo Repository mới trên GitHub:
    Truy cập github.com/new và đặt tên repository (ví dụ: sorting-studio). Để chế độ Public.
  2. Đẩy toàn bộ mã nguồn lên GitHub:
    Mở Terminal tại thư mục dự án và chạy các lệnh sau: 
    git init
git add .
git commit -m "Khoi tao Sorting Studio Visualizer"
git branch -M main
git remote add origin https://github.com/<ten-tai-khoan>/<ten-repo>.git
git push -u origin main
  3. Kích hoạt GitHub Pages:
    - Vào mục Settings của repository trên GitHub.
    - Ở thanh bên trái, chọn Pages.
    - Tại mục Build and deployment > Branch: chọn main và thư mục / (root).
    - Nhấn Save.
  4. Thưởng thức thành quả:
    Sau khoảng 30 giây đến 1 phút, trang web của bạn sẽ hoạt động trực tiếp tại địa chỉ:
    https://<ten-tai-khoan>.github.io/<ten-repo>/
